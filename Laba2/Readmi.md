# Laba2

Вторая лабораторная работа по языку Go. Шесть небольших программ (`Task1.go` – `Task6.go`),
каждая решает одно задание: условия (`if/else`), циклы (`for`), функции, строки и руны,
структуры и методы.

## Задания

| Файл | Задание |
|------|---------|
| `Task1.go` | Определение, чётное или нечётное введённое число (`n%2 == 0`) |
| `Task2.go` | Функция `Number(n)`, возвращающая `"Positive"`, `"Negative"` или `"Zero"` |
| `Task3.go` | Вывод всех чисел от 1 до 10 с помощью цикла `for` |
| `Task4.go` | Функция `Stroka(s)`, возвращающая длину строки с учётом Юникода (через `[]rune`) |
| `Task5.go` | Структура `Rectangle` и вычисление площади прямоугольника |
| `Task6.go` | Функция `average2(a, b)`, возвращающая среднее двух целых чисел |

## Запуск

Каждая программа — отдельный `package main` со своей `func main()`, поэтому запускать нужно пофайлово:

```bash
go run Task1.go
```

Замените `Task1.go` на нужный файл. В `Task1.go`, `Task2.go` и `Task4.go` после запуска
введите значение с клавиатуры.

## Теория

### Чем структура отличается от массива

**Массив** — фиксированная последовательность элементов **одного** типа. Доступ к данным —
по **индексу**:

```go
var a [3]int = [3]int{10, 20, 30}
fmt.Println(a[1]) // 20
```

**Структура** — набор полей **разных** типов, объединённых под одним именем. Доступ —
по **имени поля**:

```go
type Rectangle struct {
	Width  int
	Height int
}

r := Rectangle{Width: 10, Height: 5}
fmt.Println(r.Width) // 10
```

| Признак | Массив | Структура |
|---------|--------|-----------|
| Типы элементов | только одинаковые | любые (смешанные) |
| Доступ к данным | по индексу `a[0]` | по имени поля `r.Width` |
| Тип | размер входит в тип: `[3]int` и `[5]int` — разные типы | тип определяется набором полей |
| Назначение | однородный набор значений | одна сущность с характеристиками |
| Методы | объявить нельзя | можно: `func (r Rectangle) Area() int` |
| Обход | удобно в цикле `for i := range a` | поля перечисляются явно |

И массив, и структура — **значимые типы**: при присваивании и передаче в функцию
копируются целиком. На практике вместо массивов чаще используют **слайсы** (`[]int`) —
похожую конструкцию, но с изменяемой длиной.

### Что такое руны и чем они полезны в задании 4

`rune` — это псевдоним типа `int32`, то есть одна **кодированная позиция Юникода**
(условно «один символ»).

Строка в Go — это не массив символов, а **слайс байтов в кодировке UTF-8**.
В UTF-8 английская буква занимает 1 байт, русская — 2 байта, эмодзи — 4 байта.
Поэтому обычный `len()` считает **байты**, а не символы:

```go
len("Привет")         // 12 байт, хотя символов всего 6
len([]rune("Привет")) // 6 — корректное количество символов
```

Преобразование `[]rune(s)` разворачивает строку в **слайс рун**, где каждый элемент —
один символ, независимо от числа байт в нём. Именно этот приём используется в `Task4.go`:

```go
func Stroka(stroka string) int {
	return len([]rune(stroka))
}
```

Без `[]rune` функция возвращала бы длину в байтах и ошибалась бы на любой строке
с кириллицей или эмодзи.

Руны полезны и для корректного посимвольного обхода строки:

```go
for _, r := range "Привет" {
	fmt.Printf("%c ", r) // П р и в е т
}
```

Более экономичная альтернатива `len([]rune(s))` — `utf8.RuneCountInString(s)`:
она считает руны без создания лишнего слайса в памяти.
