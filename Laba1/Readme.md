# Laba1

Первая лабораторная работа по языку Go. Шесть небольших программ (`Task1.go` – `Task6.go`), каждая демонстрирует базовые возможности языка.

## Задания

| Файл | Описание |
|------|----------|
| `Task1.go` | Вывод текущего времени и даты (`time.Now()`, формат `02.01.2006 15:04:05`) |
| `Task2.go` | Объявление переменных разных типов (`int`, `float64`, `string`, `bool`) через `var` с выводом на экран |
| `Task3.go` | Короткое объявление переменных через `:=` и вывод текста |
| `Task4.go` | Случайные числа (`rand.IntN`), арифметические операции: сумма, разность, деление, умножение |
| `Task5.go` | Функции `Sum` и `Diff` для чисел с плавающей запятой (`rand.Float64`, форматированный вывод `%.2f`) |
| `Task6.go` | Чтение трёх чисел с клавиатуры (`fmt.Scan`) и вычисление среднего |

## Запуск

```bash
go run Task1.go
```

Замените `Task1.go` на нужный файл. Для `Task6.go` после запуска введите три числа через пробел.
